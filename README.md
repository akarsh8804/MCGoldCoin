## Crafting Recipe

Combine the following items in a crafting table:

| Ingredient | Quantity |
|:---|:---:|
| Gold Nugget | 1 |
| White Dye | 1 |

**Result:** 4 Gold Coins

## Installation

MCGoldCoin consists of two separate packs. Both must be installed for the add-on to work correctly.

### 1. Resource Pack

1. Download or clone this repository.
2. Copy the `resourcepack` folder into your Minecraft `resourcepacks` directory.
3. Rename the `resourcepack` folder to `MCGoldCoin`.
4. Launch Minecraft.
5. Enable the **MCGoldCoin** resource pack.

### 2. Datapack

1. Copy the `datapack` folder into your world's `datapacks` directory.
2. Rename the `datapack` folder to `MCGoldCoin`.
3. Open your world.
4. Run `/reload` or re-enter the world.
5. Run `/datapack list` to verify that **MCGoldCoin** is enabled.
6. Once enabled, the crafting recipe should be available.

## Compatibility

- **Edition:** Minecraft Java Edition
- **Minecraft Version:** 26.3

*Version compatibility can be adjusted by modifying the values in `pack.mcmeta`. Refer to the Minecraft Wiki for the relevant format versions:*
